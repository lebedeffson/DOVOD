# DOVOD

**Decision-Oriented Verification of Observations and Dependencies**

DOVOD объединяет проверку процедурных зависимостей по наблюдаемым демонстрациям и выбор следующего источника информации при неопределённости.

Проект исследует две связанные задачи:

1. как по конечным демонстрациям отличать реально поддерживаемые условия действия от случайно устойчивого порядка действий;
2. как при неопределённости выбирать источник дополнительной информации — наблюдение физического состояния или проверку правила процедуры.

Тексты статей и тезисов в репозитории не хранятся.

Быстрый старт:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pytest -q
python scripts/verify_reference_results.py
```

Публичный стабильный интерфейс находится в `src/procedural_ai/`. Экспериментальные сценарии разделены на `experiments/constraints/` и `experiments/information_selection/`. Прежние направления проекта перечислены в `docs/research_roadmap.md` и сохраняются отдельно от стабильного API.
