# Frozen research reference implementation

This directory preserves reviewer-era research scripts that produced the current evidence base and earlier extension branches.

It exists for continuity and auditability. New reusable code should go into `src/procedural_ai/`; new experiments should go into `experiments/`.

Major preserved families include:

- prerequisite falsification / semantic calibration / carrier evidence;
- source-aware physical-vs-semantic information acquisition;
- evidence certificates and fail-closed authorization;
- real visual routing and keyframe experiments;
- online reliability/session adaptation;
- risk-aware and selective assistance;
- cross-procedure IMPACT/IndustReal experiments;
- progressive intent, procedure compiler and runtime/XR prototypes.

Raw third-party data is intentionally not stored here. See `data/README.md`.
