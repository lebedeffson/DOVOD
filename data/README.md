# Data

This repository does **not** redistribute raw MECCANO or IMPACT media/annotations unless their original terms explicitly permit it.

## MECCANO

The verified reference implementation expects the PSR annotation archive at:

`data/external/MECCANO_PSR_Annotations.zip`

or at the path supplied through:

`PROCEDURAL_AI_MECCANO_PSR_ZIP=/absolute/path/MECCANO_PSR_Annotations.zip`

Raw RGB/video is not required for the two core algorithmic studies in this repository, but is required for the preserved visual-routing extension.

## IMPACT

IMPACT is third-party data. The repository keeps code and compact reference outputs needed to audit numerical claims, but it does not relicense the raw dataset.

See `docs/datasets.md` for the exact data boundary and preparation flow.
