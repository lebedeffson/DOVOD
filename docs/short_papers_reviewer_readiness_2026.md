# Reviewer-readiness status — final v12 short papers

This file deliberately separates what is closed by the current repository from what remains a future research gate.

## Paper A — closed

- direct counterexample semantics for unary unconditional same-state prerequisites;
- independent carrier identity and carrier-loss robustness;
- nested recording-level calibration protocol;
- finite-population carrier rarefaction;
- observational rework-context evidence;

### Not claimed as closed

- probability that an unfalsified relation is mechanically necessary;
- safety certification.

### Not claimed as closed
