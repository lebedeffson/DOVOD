# DOVOD 2026 research roadmap

The two short papers are separate studies but form one longer decision-support program.

## Paper A — next full-paper gates

Current result: direct counterexamples, independent carriers, nested calibration, rework-conditioned evidence, rarefaction and zero-failure uncertainty bounds.

Next gates:

- obtain authoritative manual/SOP or expert adjudication for **positive** REQUIRED claims;
- move from unary unconditional relations to conditional, conjunctive, temporal and resource prerequisites;
- separate observation incompleteness from true structural necessity with explicit positive-evidence models;
- validate the same falsification/calibration pipeline on additional procedures;
- evaluate reviewer-priority policies using carrier fragility and evidence saturation.

## Paper B — next full-paper gates

Current result: exact Bellman vs myopic planning, physical-vs-semantic uncertainty, cost misspecification, a separate noisy-source reliability stress, prevalidation accounting, exact state-space scaling and an analytical exact-to-myopic guard.

Next gates:

- calibrate real sensor reliability and expert/manual-review reliability;
- measure real costs (time, workload, money) instead of normalized model units;
- move repeated noisy/correlated observations **inside** sequential planning instead of testing them only in a one-step stress;
- support semantic review outcomes outside a pre-enumerated version space;
- externally replicate the full source-selection policy on a second procedure;
- compare exact, myopic and approximate/POMDP-style policies under the same calibrated environment;
- evaluate workload-level prevalidation economics over multiple sessions and procedure changes.

## Integrated DOVOD path

The two lines are complementary:

1. prerequisite falsification determines which procedural restrictions remain defensible;
2. source-aware information acquisition decides what evidence to request when action admissibility remains unresolved;
3. evidence/certificate layers can bind authorization to the exact evidence/model state that justified it;
4. runtime/XR components can consume verified decisions rather than reimplementing procedure logic.

A later integrated evaluation should test the complete loop:

`demonstrations -> candidate restrictions -> counterexample calibration -> uncertain action state -> information-source selection -> authorization/review -> auditable evidence record`.

## Preserved extension directions

The wider repository also keeps research directions on verifiable authorization/certificates, real visual evidence routing, online reliability adaptation, risk-aware procedural control, edge/runtime/XR execution, and intent-aware assistance/human-study design. These should be promoted into the stable API only after their corresponding evidence gates are met.
