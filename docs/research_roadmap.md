# Research roadmap and preserved directions

The repository separates **current core evidence** from **preserved extensions** so the public interface stays clean while the wider research program remains visible.

## Core line 1 — procedural constraint validation

Current: counterexample falsification, nested calibration, carrier robustness, rarefaction/sample-complexity, rework-conditioned analysis, prospective review priority.

Next gates:
- authoritative manual/SOP or expert adjudication for positive REQUIRED claims;
- conditional and conjunctive prerequisite classes;
- stronger cross-procedure validation.

## Core line 2 — information-source selection

Current: exact Bellman vs myopic selection, semantic-cost frontier, noisy-source Bayesian stress, cost misspecification, reliability sweeps and exact state-space scaling.

Next gates:
- live sensor and expert-review error distributions;
- repeated/correlated/adversarial misinformation;
- external source-aware replication on a second procedure.

## Preserved extension A — verifiable authorization and certificates

Evidence certificates, context-bound certificates, semantic-version authorization, certificate soundness audits and decision-certificate bridging.

## Preserved extension B — real visual evidence routing

MECCANO keyframe extraction, frozen visual policy, reference perception models, real-visual gates, IndustReal visual transfer and routing/profile experiments.

## Preserved extension C — online reliability adaptation

Online reliability heads, session adaptation, reliability probes and adaptation ablations.

## Preserved extension D — risk-aware procedural control

Risk models, action-risk context audits, progressive intent-risk logic and selective-assistance experiments.

## Preserved extension E — edge/runtime/XR execution

Quantization-policy checks, runtime benchmarks, procedure compiler, bounded-autonomy prototype, Unity/OpenXR bridge and playable runtime.

## Preserved extension F — intent-aware assistance and human study

Progressive-intent experiments and the runtime path from developer runs to feasibility pilot and preregistered human intervention study.

The preserved implementations live under `research/reference_impl/` and the runtime prototype under `prototypes/runtime/`. They are intentionally kept outside the stable import API.
